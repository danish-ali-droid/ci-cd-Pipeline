# Hotel Management Frontend

A simple Node.js frontend page for hotel management built with Express and vanilla JavaScript.

## Run locally

1. Navigate to `CI-CD/node-app-pipeline`
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the server:
   ```bash
   npm start
   ```
4. Open `http://localhost:3000`

## Features

- Add, edit, and delete hotel records
- Search hotels by name
- Persist hotel data in browser `localStorage`
- Responsive layout for desktop and tablet screens
